# Milestone history (archived)

Snapshots and logs from Steps 1–6, kept for reference only. Nothing in the project reads them,
and none of them are hash-protected.

Moved here from `reports/`:

- `step1-backup/` … `step6-backup/`: copies of the working files before each step.
- `step3-execution.log`, `step4-execution.log`, `step5-execution.log`: training and evaluation logs.
- `verification-workspace.txt`: the workspace verification outcome.

The files are unchanged, so paths inside them (and in `notebooks/exploration.ipynb`) still say
`reports/stepN-…`; those paths now refer to this folder.
